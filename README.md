# magnetic-core.github.io

Pixigo's public website, served by GitHub Pages from the root of `main`.

- [Homepage](https://pixigo.ai/)
- [Magnetic Core privacy policy](https://pixigo.ai/privacy-policy/)

The homepage lives in `index.html`; the supplied policy is preserved in
`privacy-policy/index.html`. The `.nojekyll` file keeps these HTML files unprocessed.

Domain registration and DNS remain at GoDaddy. Google Workspace handles email;
preserve the MX, SPF, DKIM, DMARC, and domain-verification records when changing
website DNS records.
