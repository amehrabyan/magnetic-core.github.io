Magnetic Core help

Keep the next move in play.

For rules and strategy, start with the Magnetic Core field guide or the interactive How to Play tutorial inside the game. This page covers the browser version's storage, installation and technical problems.

The game does not load

  1. Open pixigo.ai/magneticcore/ directly in a browser tab, with JavaScript enabled and an internet connection for the first visit.
  2. Close other Magnetic Core tabs, then reopen the game. This also allows an already downloaded update to activate.
  3. If a browser extension blocks the game itself, try another browser. Blocking advertising should not stop gameplay.

Avoid clearing site data as a first troubleshooting step. It can permanently remove locally saved scores, coins and unlocked themes.

Where is my saved progress?

Progress belongs to the browser and device where you earned it. Safari and Chrome do not share the same save, and the browser game does not sync with the native iPhone app. Private browsing, cleared site data or storage restrictions may remove progress. If storage is unavailable, an on-screen warning explains that the save lasts for that session only.

Scores, coins and unlocked themes are saved, but an unfinished board is not restored after a reload. There is no account-based cloud backup or server copy for us to restore.

Install and play offline

Open the game online and wait for “Ready for offline play” beneath it. On iPhone or iPad, use Safari → Share → Add to Home Screen. On browsers that support installation, choose Install from the browser menu or the game header. Keep enough device storage available. The game can work offline after downloading, but online support pages and ads cannot.

Sound, movement and controls

Start a game with a tap or click before checking audio; browsers can block sound until an interaction. Check the game's Music and Sound Effects switches, the tab's mute setting and device volume. Use placement assistance in Settings if dragging makes it hard to see the target cell. Display or browser zoom can also affect how much of the board fits on screen.

Advertisements and privacy choices

Browser ads are separated from the game controls and do not award coins or unlock cosmetics. They may be unavailable if blocked, offline or awaiting Google's approval. You can play regardless. Use Advertising privacy choices below the game when available, or see the browser privacy section for the data involved and your choices.

Report a problem

Email privacy@pixigo.ai with your device model, browser and version, whether you were online, and the steps that led to the issue. For a gameplay problem, mention Classic or Flux Rush and the piece or effect involved. A screenshot can help; remove personal information before sending it.

We do not need your password, payment details or private browsing history. For personal data requests, use the same address and tell us whether your request concerns the browser game or the native app.
